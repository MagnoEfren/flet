# Metric Flow

Dashboard administrativo desktop en **Python + Flet 0.85.2**, arquitectura
modular (`theme` / `models` / `services` / `components` / `views`).

- **Dashboard** — métricas (ingresos, pedidos, clientes, conversión),
  mapa de calor "Pedidos por Hora", gráfico "Rendimiento de Ventas
  Mensual", "Ventas por País" y "Top Productos"
- **Órdenes** — tabla de pedidos con badge de estado
- **Productos** — inventario con badge de stock
- **Clientes** — tabla de clientes con gasto total
- **Analítica** — métricas resumen + ventas por categoría (barras)
- **Ajustes** — perfil y preferencias (switches funcionales)

## Ejecutar

```bash
pip install -r requirements.txt
python3 main.py
```
